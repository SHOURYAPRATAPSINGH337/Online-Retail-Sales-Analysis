# Online Retail Sales Analysis

## 📌 Overview
An end-to-end sales analysis of the UCI Online Retail Dataset using Excel, SQL, and Power BI — from cleaning raw transactions to building an interactive dashboard that shows sales trends, top products, and customer behavior.

## 🎯 Objective
To understand what drives revenue for an online retailer: which products, countries, and customers contribute the most, and how sales change over time.

## 📂 Dataset
- **Source:** [UCI Machine Learning Repository – Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
- Transactions from a UK-based online retailer (invoice, product, quantity, price, customer, country, date)
- The raw file is not included in this repo because of its size — download it from the link above.

## 🛠️ Tools & Technologies
- **Excel** — data cleaning (removing duplicates, cancelled orders, missing values)
- **SQL** — querying and aggregating the data
- **Power BI** — interactive dashboard and visualizations

## 🔍 Approach
1. Cleaned the raw data in Excel (handled missing customer IDs, cancellations, negative quantities)
2. Wrote SQL queries to calculate revenue, top products, country-wise sales, and monthly trends
3. Built a Power BI dashboard with KPIs, charts, and slicers

## 📈 Key Insights
-* 1.Total Revenue reached 10.33M.*
-* 2. November generated the highest monthly revenue. *
-* 3. United Kingdom  contributed most sales. *
-* 4. A small number of products generated a large percentage of revenue. *
-* 5. Seasonal product performed strongly during peak months. *
